Get started

Install the CLI

Check available releases ↗
sh / bash / zsh 
curl -fsSL https://cli.deplexo.com/install.sh | sh

Installs the latest stable release to ~/.local/bin. Run it again to update.

The installer detects your CPU and verifies the download checksum. Read the installer or download an archive. See release notes for verified platforms.

01

Sign in

Enter the pairing code in your browser to sign in. The CLI saves your credentials in your OS keyring.

deplexo auth login
02

Choose your app

Link your working directory to an app using its dashboard UUID.

deplexo link --app <app-id>
03

Check your logs

Follow your app's runtime logs. Add --json to get one JSON object per line.

deplexo logs --follow

Using CI?

Create an API key with the permissions you need, then save it as DEPLEXO_TOKEN in your CI secret manager. Use a pinned release so builds use the same CLI version.
