Get started

Install the CLI

Check available releases ↗
sh / bash / zsh 
curl -fsSL https://cli.deplexo.com/install.sh | sh

Installs the current release to ~/.local/bin. Run it again to update.

The installer detects your CPU and verifies the download checksum. Read the installer or download an archive. It selects the latest stable release, or the latest beta while no stable release is available. See release notes for verified platforms.

01

Sign in

Enter the pairing code in your browser to sign in. The CLI saves your credentials in your OS keyring.

deplexo auth login
02

Choose your app

Run deplexo apps list to find your app's UUID, then link it to your working directory.

deplexo link --app <app-id>
03

Check your logs

Follow your app's runtime logs. Add --json to get one JSON object per line.

deplexo logs --follow

Command reference

What you can run

Link an app with deplexo link --app <app-id> to use it in the commands below. Most app commands also accept --app <app-id>. Replace <app-id> and <deployment-id> with their UUIDs. Add --help to any command to see its flags.

Apps

deplexo apps list
List your apps, their UUIDs, and current statuses.
deplexo apps get
Show details for the selected app.
deplexo apps create --name <name> --repo <url>
Create an app and its first deployment from an HTTPS Git repository URL.
deplexo apps start
Start a stopped app without rebuilding it.
deplexo apps stop --yes
Stop the app. This does not cancel an active deployment.
deplexo apps delete --yes
Delete the selected app and its resources.

Check the selected app before using --yes. Start, stop, and delete need app:start, app:stop, and app:delete permissions, respectively. Request these with auth login --scopes or use an API key with those permissions. Custom sign-in scopes replace the defaults and must include profile:read.

Deployments and logs

deplexo deploy
Rebuild the selected app from its recorded source. The command returns the queued deployment's UUID without waiting for the build.
deplexo deployments list
Show the selected app's deployment history.
deplexo deployments logs <deployment-id>
Read a snapshot of that deployment's build logs.
deplexo logs --follow
Follow runtime logs. Omit --follow for a snapshot.
deplexo apps cancel --yes
Cancel the selected app's current deployment.

deploy needs app:restart, included in new sign-ins. Sign in again if an older session lacks it.

Sign in and account

deplexo auth login
Sign in with a pairing code. Press Enter when prompted to open the browser.
deplexo auth status
Check your current sign-in with the API.
deplexo whoami
Show the account used by your token or sign-in.
deplexo auth logout
Sign out and remove this profile's saved credentials.

Local setup and CLI tools

deplexo link --app <app-id>
Link the current directory to an app.
deplexo unlink
Remove the directory's app link. The app is not deleted.
deplexo upgrade
Check for a newer CLI and ask before installing. Add --check to check only. Available in beta.3 and newer.
deplexo version
Print the installed CLI version.
deplexo completion <shell>
Generate completion scripts for Bash, zsh, fish, or PowerShell.
deplexo --help
List commands and global flags. Help, version, and completion work offline.

Use --json for machine-readable results and --no-input to disable prompts. Following logs with --json writes one JSON object per line.

Using CI?

Create an API key with the permissions you need, then save it as DEPLEXO_TOKEN in your CI secret manager. Use a pinned release so builds use the same CLI version.
