THE DEPLEXO COMMAND LINE

Deplexo, from
your terminal.

Create apps, check deployments, and follow logs without leaving your terminal.

Install the CLI ↓View releases ↗

Linux · macOS · Windows amd64 / arm64 builds

deplexo / terminal⌘

# Sign in through your browser

$ deplexo auth login

# Inspect an app

$ deplexo apps get --app <app-id>

# Follow its runtime logs

$ deplexo logs --app <app-id> --follow

$

One binary. No runtime to install.

GET STARTED

Install in your terminal.

Check available releases ↗
sh / bash / zsh 
curl -fsSL https://deplexo.github.io/cli/install.sh | sh

Installs the latest stable release to ~/.local/bin. Run it again to update.

The installer detects your CPU and verifies the download checksum. Read the installer or download an archive. See release notes for verified platforms.

01

Sign in

Approve the pairing code in your browser. Credentials stay in your OS keyring.

deplexo auth login
02

Choose your app

Link a directory using the app UUID from your dashboard.

deplexo link --app <app-id>
03

Check your logs

Follow runtime logs, or add --json for one JSON object per line.

deplexo logs --follow

Using CI?

Set DEPLEXO_TOKEN through your secret manager. Use a pinned release for repeatable builds.
